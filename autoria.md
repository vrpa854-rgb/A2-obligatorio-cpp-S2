# Declaración de autoría — Obligatorio 1

## Ejercicio 1
- Código visto en clase: TAD AVL (inserción con rotaciones), tomado como base y extendido por el equipo.
- Implementación propia: los métodos Existe e InOrderRango del AVL (con la poda por rango para cumplir O(log K + R)) y el programa principal.

## Ejercicio 2
- Código visto en clase: TAD Hash, modificado por el equipo para que sea una tabla abierta con encadenamiento (el de clase era cerrado) y con rehash agregado.
- Implementación propia: la clave por conteo de letras, la función de hash con la regla de Horner, el programa principal y los contadores que mantienen la última línea de la salida.

## Ejercicio 3
- Código visto en clase: TAD Heap, simplificado por el equipo para que se comporte únicamente como heap binario (se eliminaron las funciones de hash y equivalencia pensadas para la cola de prioridad extendida).
- Implementación propia: el programa principal.

## Ejercicio 4
- Código visto en clase: TAD Heap (con la misma simplificación del ejercicio 3) y TAD Grafo con listas de adyacencia.
- Implementación propia: el programa principal, que resuelve el problema con orden topológico (algoritmo de Kahn) usando el heap para elegir el próximo módulo.

## Ejercicio 5
- Código visto en clase: TAD MFSet (conjuntos disjuntos con compresión de caminos y unión por altura) y TAD Heap.
- Implementación propia: el programa principal, que resuelve el problema con el algoritmo de Kruskal.

## Justificación
- Utilizamos la IA Claude como una segunda mirada para verificar que el código cumpliera con los órdenes que pide la letra. Las soluciones y el razonamiento son del equipo: le pasamos el código junto con las restricciones y le pedimos que lo revisara, para detectar errores que se nos hubieran escapado. No generó el código del ejercicio.
